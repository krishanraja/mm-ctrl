# CTRL Phase 5 playable complete-loop proof brief

**Brief revision:** `PB-001`

**Status:** Active R2 same-spine correction. Synthetic product proof only. No production implementation authority.

## What R2 must prove

A cold reviewer can use CTRL without a walkthrough and explain all four points:

1. CTRL sharpens one consequential AI-transition decision rather than vending an answer.
2. The system changes its challenge and proposed next move in response to the leader's input.
3. The leader can correct or resist CTRL and still owns the final call.
4. The Brain changes only after explicit approval, making the next interaction more useful and producing an inspectable portable receipt.

Looking polished is not a pass signal. A static storyboard, carousel or compositional mock fails.

## Bounded fixture

Use the existing synthetic marketing decision:

> Whether to reorient marketing around AI and redesign the division around high-agency, high-taste judgement and systems-administration capabilities.

Keep these evidence boundaries visible:

- Leader view: current reluctance and low-value production suggest the existing shape is wrong.
- Observed: one hour-long meeting produced a social-post direction that could have been prepared as varied, standards-governed options before the meeting.
- Known gap: strategy, incentives and success measures were not yet committed beyond encouraging more Claude use.
- Not established: which current people can succeed under a clear operating model.

No named-person evaluation or employment recommendation is permitted.

## Playable state sequence

### 1. Start with the real call

Show the decision and the leader's current view in their own words. The single action is to challenge the view. Voice is immediately available.

### 2. Ask one route-changing question

Ask which unknown would most change the call: strategic direction, incentives and measures, demonstrated team capability, or uncertainty about the biggest unknown. The leader selects; the system does the classification work.

### 3. Produce a responsive contrast

The chosen unknown changes the visible contrast, evidence boundary and explanation. Separate leader statement, observation, interpretation and unknown. Let the leader accept, resist, correct or reject relevance.

### 4. Return an owned call and bounded test

Propose a decision that remains editable and a smallest useful next test. The proposal must distinguish redesigning the operating model from judging current people.

### 5. Offer one optional Brain learning

Show exactly one proposed reusable principle. `Keep`, `Edit` and `Skip` are equally legitimate. No durable change occurs before explicit approval.

### 6. Make compounding value visible

After approval, show what CTRL will remember next time, what remains unresolved and that an owned copy is ready. Technical Git or Markdown detail stays behind `See what changed`.

## Interaction requirements

- One ask per state.
- Tap first, voice immediately available, typing optional.
- Deterministic branch logic makes the prototype honestly responsive without pretending a live model is running.
- Selection changes the contrast, owned-call wording, proposed test and Brain learning.
- Correction changes the returned decision in the same session.
- Keeping or skipping the learning produces visibly different final Brain states.
- Back, leave and restart routes are safe.
- Current, loading, recovery, reduced-motion, narrow-width and keyboard-height states remain usable.
- No dashboard, feed, chat transcript, evidence-classification task, technical metadata wall or explanatory tour.

## Cold-review gate

Without explanation from the maker, the reviewer must be able to:

- complete the loop in roughly five minutes;
- point to one output caused by their own selection;
- correct CTRL and see the correction respected;
- explain what CTRL learned, or confirm it learned nothing;
- identify what remains unknown;
- distinguish current value from value that compounds next time.

If the reviewer still sees only a polished mock, R2 fails. If the Evidence Lens still reads as a truth revealer or creates unnecessary cognitive work, this is rejection two and the next move is fresh divergence.

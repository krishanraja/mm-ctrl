## Classification

- Product rule: partial pass. The decision table is now useful enough to preserve, but the Brain must actively sharpen the decision rather than only present a recommendation.
- Interaction: revise. One quiet invitation should open one contextual question at a time.
- Data truth: revise. The deeper layer must distinguish what the leader can answer, what the Brain can find, and what an earlier source-backed decision suggests.
- Copy: revise. `Working route` is internal language and requires interpretation.
- Main information structure: preserve. No new dashboard grid, rail, explanatory panel or decorative image.

## Founder ruling carried into R3

Keep the decision table simple. Make depth available, not compulsory. The Brain should ask route-specific questions that could change the call, explain why each matters, and separate leader knowledge, missing evidence and prior-decision patterns. Replace `Working route` with a plain label that communicates provisional recommendation.

R2 remains a recoverable baseline. This gate does not approve React implementation, production data, merge or release.

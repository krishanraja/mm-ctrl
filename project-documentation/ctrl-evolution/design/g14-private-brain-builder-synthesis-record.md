## Design task contract

**STATE OF USE:** Krish opens one customer on desktop before a Mindmake session or on mobile immediately after evidence arrives. He has seconds to learn what deserves attention and minutes to prepare.

**USER + ACTION:** Krish must understand one supported intervention, why the latest evidence made it timely, what it could help the customer become better at, and how to prepare, adapt, inspect or reject it without administering memory.

**GOVERNING RULE:** One supported customer intervention owns the first frame. It is a proposal from current evidence, not an answer or autonomous instruction. Useful-now meaning and one deepening route sit behind it. Krish owns the session.

**DATA TRUTH:** One synthetic fixture contains five sources, ten Brain items, five allowed typed relationships, one latest-evidence event, one changed interpretation, one weakened interpretation, one supported intervention, one gap, one private ask and all required fallback states. Every visible evidence claim must resolve to the fixture.

**MATERIALITY:** Material. This proof must receive a cold founder reaction before implementation.

**BRAND + VOICE:** Extend the approved G13 R2 instrument language without copying its map-first information architecture. Use deep ink, warm cream, semantic mint and amber, the recorded type roles, restrained line iconography, meaningful settled motion and zero guff. Mindy is excluded. CTRL is a replaceable quiet working label.

**AUTHORITY:** Local synthetic proof, deterministic validation, render screenshots, Git commit and branch push only. No production account, schema, ingestion, inference, persistence, send, deployment or release.

**PROOF:** 390 x 844 and 1440 x 900. Representative, sparse, quiet, loading, stale and recoverable error states. Keyboard, visible focus, reduced motion, 44px controls, no horizontal overflow, no console errors, exact claim-to-fixture trace and a cold founder reaction.

## Selection rationale

Concept A is the only eligible spine that obeys the locked G14 hierarchy without reinterpretation. It makes the intervention readable before exploration, exposes a bounded evidence-to-action loop, and can abstain when evidence is insufficient. It is also the cheapest concept to express truthfully over the current Brain kernel.

Concept B has the highest visual ceiling and best continuity with R2, but makes Krish explore the Brain before discovering the move. Concept C has the strongest participant quality, but its likely-response framing overclaims customer behaviour and its conversation-first shell risks becoming a generic assistant.

- an in-place customer-view lens over the same canonical items.

From Concept C:

## Forbidden synthesis

Do not place an intervention card over a full map with a chat drawer beside it. That competent collage would make three objects compete, recreate a dashboard and hide the answer to what deserves attention now.

One intervention owns the frame. The causal change trace explains it. The private ask adapts it. The Living Brain proves it. None is an equal panel.

## R1 interaction sequence

### 1. Now

Open with the intervention title and directive. Directly below, state its standing, next session, three source references and the latest evidence event. The primary action prepares the contrast. Secondary actions reveal why this move or rotate it.

### 2. Change trace

Show one exact evidence assertion, the earlier interpretation, the supported replacement and what remains unresolved. The weakened interpretation stays in history. Nothing is silently deleted. The trace ends at the intervention and labels future learning as a test, not an outcome.

### 3. Prepare

Show the exact opening question, the paired material to bring, four listening signals, what the move would test and a fallback if the live conversation moves elsewhere. Krish can copy the card, reshape the move, rotate to a causally different alternative or reject the underlying read.

### 4. Private ask

Accept one optional tiny context update by chip or text. Return evidence-linked session guidance and one next question. Label the response operator-private and provisional. It changes no durable Brain item.

### 5. Living Brain

Open only on request. Render the ten fixture items, five allowed typed relationships and one changed standing. The selected intervention remains legible. The discarded interpretation is visually historical and cannot steer. Spatial distance carries no semantic claim.

### 6. Customer preview

Show the exact customer-private personal meaning produced from the same fixture. State which operator-private material remains outside it. Include no send or publish action.

### 7. Fallback state routes

Hash routes expose `#sparse`, `#quiet`, `#loading`, `#stale` and `#error` for verification. They preserve the latest verified meaning and never manufacture an intervention.

## Feasibility against current architecture

| Required object | Fixture/source | Current-kernel fit |
|---|---|---|
| Evidence arrival | `latest_evidence_event` + `sources` | New event projection over existing provenance model |
| Current and weakened meaning | `brain_items` + event changes | Existing version, standing and correction concepts |
| Typed relationships | `relationships` | Restricted to G13 allowed types: supports, in tension with, exemplifies, informs and qualifies |
| Intervention | `intervention` | New bounded projection object; it does not become a Brain item by default |
| Useful-now customer meaning | `ready_now` | Customer-private portrait projection over canonical refs |
| Deepening route | `deepen_route` | One evidence-gap projection; no completeness score |
| Private ask | `private_ask` | Disposable session guidance; durable effect explicitly none |
| Customer preview | `customer_preview` | Same-Brain audience projection; no second truth store |
| Fallbacks | `fallback_states` | Deterministic renderer states |

No graph database, vector layer, live meeting connector, new semantic relationship type or production schema is required to prove the experience.

## Binding pre-show checks

1. The intervention is understandable before any control is used.
2. New evidence, changed interpretation, weakened history and prospective learning are visible and fixture-resolvable.
3. Prepare, reshape, rotate, reject and inspect remain distinct operator choices.
4. The customer benefit is personal and specific.
5. The map is optional proof, not opening spectacle.
6. The private ask is bounded and cannot mutate durable truth.
7. Sparse and quiet states do not manufacture urgency.
8. All audience labels and exclusions remain clear without technical prose.
9. All copy performs an action, evidence, state or meaning job.
10. The current render, not stale source, is shown to Krish without a persuasive walkthrough.

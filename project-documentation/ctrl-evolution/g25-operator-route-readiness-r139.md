# G25 operator route readiness, R139

Status: `route_connection_blocked_by_design`

R139 prevents a dangerous shortcut. The live R138 review question does not make the surrounding Decision Bench live. The customer identity, decision framing, current read, three routes, questions, evidence groups, personal patterns, standards, unknowns, prior decisions, recommendations, Claude brief and returned-work audit are still generated from a synthetic fixture or static code.

The new pure evaluator admits a route only when authentication, stable operator identity, server-verified workspace selection, complete decision projection and review projection all bind to the exact same isolated project, workspace and decision. It refuses the global product client and refuses any production collision.

## Current result

The intended future route shape is:

`/operator/workspaces/{workspace UUID}/decisions/{decision UUID}`

No application route has been added. The current R138 composition is blocked because its complete decision projection is synthetic and its five-field review packet is not yet bound to the displayed decision identity.

## What this changes

- A live sliver can no longer be treated as proof that a whole customer surface is live.
- A workspace URL is a request, not authority.
- Authentication must come from the same dedicated environment client as the data.
- The next build object is the complete operator decision projection, not another page or route switch.

## What remains closed

Persistent routing, real customer data, the production client, customer participation, production, merge and release remain closed.

# G25 private rendered operator composition, R138

Status: `private_rendered_composition_passed`

R138 closes the browser gap left by R135 without creating a route or changing the approved experience. A disposable authenticated operator opened the exact Decision Bench through a dedicated local entrypoint whose Supabase client was hard-bound to the isolated `legibility` project.

## What was proved

- The desktop instrument made one live call through `getOperatorPendingQueue` and the exact R131 strict parser.
- The rendered signal matched the five allowed fields: review packet ID, question, headline, consequence and ready time.
- The packet ID was not rendered. No hash, raw packet, private denial reason or owner decision control reached the page.
- Clipboard success followed a confirmed browser write of the exact question.
- A workspace outside the operator's grant rendered the same absence as an unavailable signal.
- At 320 by 568, the later founder-approved R137 Decision Session remained the only active projection, fit the viewport and issued zero hidden review calls.
- The owner standard and packet state did not change. The operator still could not decide for the owner.
- The exact cleanup readback returned zero for all eleven disposable identity, authority, receipt and candidate categories after the successful browser run.
- A deterministic failure immediately after hosted row creation exercised the failure lifecycle. The child failed with the expected non-zero exit, owned its cleanup and returned the same eleven zero-count readbacks.
- The staged browser session was consumed into memory-only storage. Every browser scenario verified that the local-storage auth key had been removed.
- Production writes were zero.

## Deliberate limits

The proof is local and private. It does not add or enable an application route, use the global production client, create a persistent operator account, alter the customer surface, write customer data, merge, release or touch production.

The next product integration step needs an explicit route contract binding authentication, environment and selected workspace. This result does not allow the application to infer those bindings from URL text or fall back to the production client.

## Root cause

A question validator without an atomic session reservation can validate several simultaneous questions. A signed free-text fingerprint does not prove which plain-language interpretation the person saw. A registry carrying the expected string is not an authority boundary. A correction reference is not evidence that its target exists or has the claimed state.

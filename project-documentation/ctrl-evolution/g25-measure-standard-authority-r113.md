# G25 held-out measurement authority R113

R113 closes the first trustworthy path from a leader grading unfamiliar work to the word Verified. It does not claim that one synthetic perfect result proves universal judgement quality. It proves that the instrument cannot see its answer key, hide provider failures as agreement or publish a result after the underlying standard changes.

## What the model sees

For each held-out item, the Standard lens receives the unfamiliar work, the leader's current compiled criteria and only training examples. It does not receive the leader's verdict on that item. The database keeps that verdict hidden until all predictions have been fixed and usage-receipted.

The model returns criterion-level findings with exact quoted passages. Code enforcement drops invented criteria and unverified quotes. Any enforced break blocks the item. Holds and actionable borderlines do not block it. No scoreable finding becomes insufficient, never a quiet hold.

## What the database decides

The atomic finalizer re-reads the pinned source, rejects any change, verifies that every target has exactly one prediction, rejects any held-out exemplar, requires one paid-call receipt for every scored item and only then joins predictions to hidden grades.

It stores TP, FP, FN and TN separately, plus every skipped and insufficient item. Precision, recall and true negative rate remain separate. The release gate now requires ten items that actually reached the confusion matrix. Ten graded items with nine provider failures can no longer borrow the denominator and call one correct answer Verified.

The measurement is historical and inspectable. The current standard artifact receives the exact counts, metrics, self-agreement and measurement identity in metadata. The product reader re-derives its label from those numbers instead of trusting a stored word.

## Hosted result

One real ten-item measurement on the isolated Legibility project completed with ten usage receipts. Five pieces the synthetic leader would reject were caught, and five they would send were left alone. The resulting precision, recall and TNR were each 1.00, so this fixture earned Verified under the provisional thresholds.

The significance is the path, not the perfect synthetic score. Exact replay returned the same run; a changed payload under the same request ID conflicted; another account saw zero rows; direct capability use was forbidden; run and spend ceilings returned 429; a changed source was refused with no measurement row; and cleanup left no users, runs, measurements or usage fixtures.

## What changed around it

The old operator evaluator was hard-coded to production, could mint a magic-link session and contained a second copy of the evaluation loop. It is now a thin exact-project wrapper over `measure-standard`. It cannot mint a session, contains no scoring logic and independently re-derives the returned label through the shared release function.

The weekly deterministic probe remains only a drift screen. It is not the held-out model instrument and cannot earn Verified.

## Boundary

This is an isolated technical and synthetic evidence result. Real-leader validity, difficult category-specific work, longitudinal calibration, customer experience and production operations remain unproved. Production was not mutated. No merge, cutover, release or legacy retirement is authorised.

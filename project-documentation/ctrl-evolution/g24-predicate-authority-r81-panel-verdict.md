Some visible answers, semantic referents, Brain standing, correction records, external policy and conditional obligation sets still originate from the object under review or from a caller argument. A cryptographically intact envelope cannot repair a question that asked for the wrong judgement or a reference that was never resolved.

## R82 repair rule

R82 must make every claimed relationship authority-resolved and type-aligned:

1. one versioned question-and-effect contract per atomic human dependency or judgement shape;
2. exact selected-option validation with positive signed vectors for every displayed option and representative purpose, frame, value, boundary, stop and revisit judgements;
3. immutable assertion-byte, Brain-standing, contrary-assertion and derived-input receipt resolvers with recomputed fingerprints;
4. authoritative sealed close-obligation state rather than proof-supplied conditional IDs;
5. a trusted correction record store bound to the authority bundle, with resolved trigger, proof, use, artifact, history and descendant-block effects and a generic graph verifier;
6. effective external policies only from the contract registry, with test-only execution separated from authority, closed protocol evidence, resolved terminal receipts, non-negative time bounds and durable transactional replay or consumption state;
7. total validators that return typed rejection for arbitrary JSON rather than throwing; and
8. a pinned mandatory vector inventory that cannot silently shrink.

No R82 founder-ready receipt may exist until all seven roles pass one exact frozen commit. Runtime, database, UI, deployment, merge, release and external authority remain closed.

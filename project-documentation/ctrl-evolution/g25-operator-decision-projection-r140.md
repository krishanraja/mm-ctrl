# G25 complete operator decision projection, R140

Status: `strict_projection_contract_passed`

R140 defines the complete read membrane required before the private operator route can become real. It replaces the idea that one live review signal is enough with an exact, purpose-bound object for the whole decision-preparation surface.

## What it carries

- exact environment, authority, workspace, subject and decision identity;
- leader and relationship context;
- the consequential decision, provisional view and three materially different routes;
- current Brain read, strongest counter-case and important unknown;
- personal patterns, standards, corrections and prior decisions;
- route-changing questions with answer modes;
- atomic evidence projections with source lineage, origin audience, freshness, standing and redaction state;
- recommended move and Claude handoff constraints;
- optional returned-work audit;
- honest sufficient or sparse coverage; and
- an optional review signal bound to the same decision.

## What it forbids

The strict parser rejects raw or unknown fields, wrong environment, authority substitution, invalid freshness, future evidence, duplicate identities, missing routes, questions without valid routes, broken prior-decision or evidence references, invalid choice contracts, returned-work audit references that do not exist and review signals from another decision.

On any failure it returns reasons and a null projection. There is no partially trusted object.

## Current standing

The contract passes 26 adversarial tests. The existing synthetic Decision Bench fixture is a negative control and is rejected. No server producer or application consumer exists yet, so a real route remains closed.

# G25 complete operator decision projection, R140 strategy

## Outcome

Freeze the smallest complete live projection that could honestly replace the synthetic Decision Bench inputs without exposing raw Brain records or weakening human authority.

## Product reason

Krish cannot prepare a consequential customer session from one live question surrounded by synthetic context. The operator surface must tell one coherent truth about the exact leader, decision, routes, evidence, judgement patterns, standards, unknowns, prior decisions, recommended move and any returned work.

The projection is not a database dump. It is a purpose-bound, read-only preparation object. It carries only the material needed for operator judgement and preserves the difference between evidence, interpretation, counter-case, unknown and human-owned call.

## Contract

The projection must:

1. Be generated in the isolated environment under an unexpired owner authority event and finite operator grant for `delivery_team_private` and `operator_decision_preparation`.
2. Bind workspace, subject and decision identities exactly.
3. Carry a valid generation and freshness window.
4. Contain exactly three materially different routes with evidence for, evidence against, counter-case and decision effect.
5. Give every route at least one route-changing question with the correct answer contract.
6. Use atomic evidence projections with distinct evidence and source identities, origin audience, freshness, standing and redaction state. Raw source bodies are forbidden.
7. Bind every current read, pattern, standard, correction, prior decision, question, recommended move, Claude handoff and returned-work finding to existing evidence atoms.
8. Preserve honest sparse state and permit returned work or a review signal to be absent.
9. Bind any review signal to the same decision.
10. Reject extra fields, broken references, duplicate identities, future evidence, expired authority and cross-decision substitution without returning a partial projection.

## Deliberate limits

R140 is a strict parser and contract proof. It does not create a server projection, query a database, connect the React instrument, add a route, use real customer data, deploy, merge or release.

## Next safe action

Build one server-side isolated projection candidate from existing authoritative stores and a disposable complete decision fixture. Prove operator authority, exact field shape, negative cross-workspace and cross-decision cases, no raw source leakage, freshness, cleanup and zero production writes before any React integration.

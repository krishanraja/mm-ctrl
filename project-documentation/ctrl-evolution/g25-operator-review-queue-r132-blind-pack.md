# Blind pack: selected-customer operator review signal

## Sanitized task

A human adviser is inside one leader’s private working room. The leader’s governed AI Brain has identified one checked change to the leader’s personal working standard. Only the leader may accept or reject it. The adviser needs to notice the pending change and bring the exact question into the next live session without seeing the raw private packet or gaining decision authority.

Judge three anonymous interaction spines in `public/g25-operator-review-queue-concepts-r132.html` using `?candidate=a`, `?candidate=b` and `?candidate=c`. Candidate order must be randomized independently by each judge.

## Fixed server truth

The selected workspace returns either no available item or exactly:

- review packet ID;
- question;
- headline;
- consequence; and
- ready time.

It returns no evidence, packet, hashes, private denial reason or decision control. The current product already contains the richer consequential-decision instrument shown behind the concepts. This signal must remain subordinate to that work.

## Required states and viewports

- ready;
- empty or unavailable, which must remain publicly indistinguishable;
- long but valid copy;
- 1440 × 900 desktop;
- 390 × 844 phone;
- 320 × 568 narrow phone;
- keyboard and reduced motion.

## Non-negotiable constraints

- operator-only concept, not the deferred customer self-service surface;
- immediate comprehension without product vocabulary;
- Maya’s authority is unambiguous;
- no generic AI copy, fake insight, decorative visualisation, sparkle grammar or confidence theatre;
- no more data or action than the server truth supports;
- one calm useful action at most;
- no prompt, send, notification or customer-contact behavior is implied;
- empty and unavailable state disclose no access detail;
- mobile is not a squeezed desktop;
- focus returns correctly when a disclosure closes;
- approval, release and production authority remain closed.

## Blind exclusions

Do not use builder rationale, conversation history, previous founder feedback, another judge’s verdict or any stated preferred candidate during the first pass.

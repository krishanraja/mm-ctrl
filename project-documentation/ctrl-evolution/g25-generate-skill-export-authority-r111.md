# G25 R111: portable skill authority

R111 turns the compiled standard into the first recoverable, inspectable and portable personal AI package on the isolated `legibility` project.

It keeps the valuable legacy machinery:

- triage distinguishes a reusable skill from a memory fact, style or custom instruction;
- the model receives the leader's compiled criteria, evidence, graded examples and authorised Brain context;
- every material rule must point to a criterion or a source span when those pointers exist;
- one repair pass may edit provenance failures;
- deterministic code marks any remaining unsupported rule as `NOT ESTABLISHED` before release;
- the package contains a router, focused leaves, examples, holdout prompts and a readable standard; and
- the ZIP and flattened artifact remain portable outside the live database.

It replaces the unsafe authority model:

- the route uses the caller JWT and RLS, never the service role;
- a separate private capability is required for every database authority RPC;
- the exact request has one stable identity and conflicting reuse fails;
- a source snapshot covers current criteria, evidence, graded work, memory, patterns, decisions, profile and latest standard;
- a changed Brain refuses stale finalization;
- run and recorded-spend ceilings block before another model call;
- every paid pass must have a durable usage receipt;
- the private ZIP is uploaded under the owner's folder and hashed;
- skill, artifact, cited spans, provenance, lineage and terminal run state commit in one transaction; and
- a late database failure removes the ZIP and leaves no persuasive partial package.

This proves one isolated authority and transaction boundary. It does not prove that a real leader will value the generated skill, that the package performs well in multiple agent environments, or that production should be cut over.

Production remains untouched. Merge, cutover and legacy retirement remain separately gated.

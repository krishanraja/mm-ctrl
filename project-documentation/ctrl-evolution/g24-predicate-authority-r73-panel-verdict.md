## Exact R74 repair

1. Bind each human-answerable field to the decision-frame reference, version and standing required by that transition, including explicit absence or not-yet-created proof before acceptance.
2. Limit external issuers to atomic fact kinds they actually own, never broader legal or semantic conclusions.
3. Require exactly one founder-locked protocol per externally authoritative fact kind: an immutable authority lease, or online conditional verify-and-consume bound to the CTRL transaction nonce.
4. Bind assertion id, issuer fact revision, signed source head, fact-level revocation epoch, exact TTL, maximum clock skew and verification time.
5. Treat the assertion as evidence-only and return `indeterminate` when the issuer cannot provide either protocol.
6. Forbid hybrid ownership unless one exact precedence rule names the sole authority for the fact kind.
7. Specify idempotent finalization and reconciliation for external success/local rollback, local success/lost acknowledgement and concurrent replay.

# G21 durable judge histories

Status: active append-only calibration record

These files preserve how each permanent judge interpreted its owned truth at consequential review points, what it protected, what failed and what later evidence changed. They are not personalities, simulated emotions or founder approval.

## Loading rule

The histories are excluded from Pack A and every sealed first pass. A judge first reviews the current frozen artifact without prior verdicts, builder rationale or founder prediction. After those rulings freeze, the relevant history may enter Pack B for calibration and Pack C for cross-examination.

This prevents anchoring while retaining institutional memory. A later pass does not erase an earlier failure. Every entry links to the immutable raw ruling that supports it.

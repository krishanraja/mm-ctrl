## One definition of the bytes

Result and response blobs now use one explicit canonical-JSON UTF-8 authority: exact versioned schema resolution, Unicode-scalar key order, preserved array order, minimal JSON escaping, no insignificant whitespace, no BOM and byte-for-byte reserialization equality. ## The operation decides the result type

Every success and result blob binds the operation class, its evaluator ABI export, the selected concrete result schema and any discriminator branch. For ordinary results, exported and selected schemas must be identical. For `use_release`, the selected schema must be the exact member selected by the exported union discriminator.

A universal result fingerprint binds workspace, operation, exported schema, selected schema, branch and the hash of the exact canonical bytes. This remains deterministic for every public operation while branch validation retains its richer domain semantics.

## The response is evidence, not a dangling reference

Committed response bytes now live in their own closed, immutable, content-hashed blob row. The committed response schema is versioned. Its decoded fields must equal the operation, result blob and committed-success row.

The result blob, response blob and success row commit in one serializable transaction or none exists. A missing, duplicate, malformed, mistyped or mismatched record holds the operation without returning success or producing the protected effect.
